Index of /kodi/

The OnScreen add-on for Kodi 20 and later. In Kodi, turn on Settings → System → Add-ons → Unknown sources, add https://on-screen.tv/kodi/ as a source in the File manager, use Add-ons → Install from zip file on the file below, then install OnScreen from Install from repository → OnScreen Add-ons. Kodi keeps it up to date from then on.
