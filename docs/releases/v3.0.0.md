# OnScreen v3.0.0

The first release of the v3 line. v3.0 puts the apps and the server's own
text in Spanish and Simplified Chinese, tone-maps Dolby Vision profile 5 to
SDR, encodes Dolby audio for AV receivers, makes search forgive partial
words, accents and typos (with search inside a library and an A–Z rail),
and converts Dolby Vision profile 7 to 8.1 in the standard Docker image
too. It removes the `/api/v1` routes and fields that no OnScreen app used,
which is why the major version changes; no app needs an update for that.
Behind those are a security review of the whole server and of every
client, and the server side of the new Roku channel, Meta Quest app, Kodi
add-on and Android Auto.

Changes since **v2.7.0** (2026-11-03): PRs #165–#301. The full record is
the `[v3.0.0]` section of [CHANGELOG.md](../../CHANGELOG.md).

## Before you upgrade

- **Back up the database.**
- **Migrations 00062 to 00065** apply at startup with `AUTO_MIGRATE=true`
  (or run the migrate step first). 00062 adds a folded copy of every title
  for search, which rewrites every `media_items` row under a table lock:
  leave free disk for a second copy of that table and its indexes, and
  expect about 15 s per 500k items. Rehearsed from v2.7.0 with data: schema
  61 → 65, sign-ins kept, nothing lost.
- **Docker:** pull `:3.0` or `:3.0.0`. An install pinned to `:2` or `:2.7`
  stays on v2.7.
- **Remote transcode workers:** upgrade them with the server. A v2.7 worker
  can't serve the whole-film remux that Roku 1.2 asks for; until every
  worker runs v3, set `TRANSCODE_VOD_REMUX=false`.
- **Scripts and integrations:** check them against "Removed from the API"
  in the CHANGELOG. API error messages now follow `Accept-Language`; branch
  on the error `code`, which doesn't change.
- **SAML:** an IdP that uses the artifact binding must switch to
  HTTP-POST.
- **Parental time windows** use the server's time zone: set `TZ`, or
  **Settings ▸ System ▸ Time zone**.

Step by step: [deployment.md › v2.7.x → v3.0.0](../deployment.md#v27x--v300).

## Highlights

- **Spanish and Simplified Chinese.** Every app has an interface-language
  setting, saved to the account so the user's other apps follow (Roku:
  English and Spanish), and the server's errors, emails and notifications
  follow it too. These are machine translations that no fluent speaker has
  reviewed yet; corrections are welcome
  ([i18n.md › Correcting a translation](../i18n.md#correcting-a-translation)).
- **Dolby Vision profile 5 on any screen.** A worker running OnScreen's GPU
  image tone-maps it to SDR with each frame's Dolby Vision metadata; before,
  profile 5 was refused wherever the screen had no Dolby Vision.
- **Profile 7 → 8.1 in the standard image**, not only the GPU one.
- **Dolby surround for receivers.** Where the server used to encode a
  multichannel track to AAC for a client that bitstreams to an AV receiver,
  it encodes 5.1 E-AC-3 (or AC-3).
- **Search that forgives** partial words ("avat"), missing accents
  ("amelie") and typos ("lord of the rinsg"), search inside one library,
  and an A–Z rail on title-sorted libraries.
- **A whole-film remux for Roku:** for an indexed MKV the channel gets one
  complete playlist, so its pause bar shows the film's length instead of
  "Rewind live TV".
- **"Play on…" reaches a Roku**, and the web player says where the title
  went.
- **Security review** of the whole server (2026-11-14) and of every client
  (2026-11-15): crafted images and memory bombs at scan time, managed
  profiles that follow their owner, atomic last-admin protection, SAML
  assertion checks and more ([security.md](../security.md)).

## Apps

- **Roku:** in the Roku Channel Store since 2026-11-09 (US, Canada, UK).
  1.2.0, in Roku's review, plays a remux as a whole film and frees the
  server when you leave.
- **Meta Quest:** the phone app's 2D panel build, in Meta's review.
- **Android phone:** Android Auto (music, audiobooks, podcasts); on tablets
  and Chromebooks a navigation rail, two-pane pages and keyboard shortcuts.
- **Android TV / Fire TV:** e-books open their title page, and Google Play
  lists the app on TVs that don't report a landscape screen. Fire TV 1.6.0
  is in Amazon's review.
- **TV web apps:** LG gets a package for its Full HD models and scrubs on
  a held ←/→; Samsung loses the white dot and the overscan and shows its
  seeks; the Xbox's B button works after the server prompt (with the
  server).
- **Desktop:** DSD (as PCM, or DoP on request), ALAC in the native engine,
  Steam Deck TV mode, and a Microsoft Store package that's ready to submit.
- **Kodi:** a new add-on for Kodi 20 and later, from the repository at
  [on-screen.tv/kodi](https://on-screen.tv/kodi/).

Store state per platform: [comparison-matrix.md](../comparison-matrix.md).

## Fixes

- Retention runs on server-only installs, scheduled tasks don't overlap
  themselves, and the scan concurrency setting is enforced.
- Stopping playback survives a hang-up, and a Roku's stop now ends its
  ffmpeg instead of leaving it to the idle sweep.
- Notifications reach every API instance (through Valkey), and parental
  time windows use the household's time zone.
- Web libraries keep loading past the first page on tall screens, and a
  photo opened outside the grid pages through its library.

---

## Known limitations

- Spanish and Chinese are unreviewed machine translations; Roku has no
  Chinese, and the Xbox's Chinese fonts are unchecked.
- Dolby Vision profile 5 needs a worker with the GPU image (NVIDIA);
  elsewhere it is still refused. The Windows installer and the Linux
  tarball still play profile 7 from its HDR10 base.
- "Play on…" to a Roku is held by one API instance; with several instances
  behind a load balancer it can be lost.
- Steam Deck TV mode hasn't run on a Deck, and DSD over DoP hasn't been
  tried on a DoP DAC.
- The published Kodi add-on (0.2.0) predates the 2026-11-15 review's Kodi
  fixes; they come in its next version.
