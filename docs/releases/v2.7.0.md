# OnScreen v2.7.0

The last server release of the v2 line. v2.7 finishes the plugin host
(metadata and scheduled-task plugins), carries audio passthrough through
full transcodes and matches files against a client's H.264 / HEVC profile
and level, backs up new installs by default with a restore drill, and ships
a monitoring pack. Since that batch it also holds background ffmpeg work
back so it can't starve the server, makes Safari play again, and brings the
Xbox app to HEVC, HDR10 and Dolby Vision through the console's own player.

Changes since **v2.6.1** (2026-10-19): PRs #142–#162, including v2.6.2,
which was prepared but never tagged. The full record is the `[v2.7.0]` and
`[v2.6.2]` sections of [CHANGELOG.md](../../CHANGELOG.md).

---

## Before you upgrade

- **Back up the database.**
- **Migrations 00058 to 00061** apply at startup with `AUTO_MIGRATE=true`
  (or run the migrate step first). They add plugin tasks, the video
  profile/level columns and a faster label permission check, and rewrite no
  existing rows. Rehearsed from v2.6.1 with data: schema 57 → 61, nothing
  lost.
- **Remote transcode workers:** upgrade them too. A v2.6 worker still works
  but ignores the new encoder level flags.
- **Backups:** only a fresh install gets the daily `Database backup` task.
  On an upgraded server, create it in **Settings ▸ Tasks** if you don't back
  up another way, and in Docker mount a volume at `/var/backups/onscreen`.
- **Profile / level matching** needs a re-probe of files already in the
  library (`POST /api/v1/maintenance/reprobe-metadata`, then a scan); until
  then they're matched as before.

Step by step: [deployment.md › v2.6.x → v2.7.0](../deployment.md#v26x--v270).

## Highlights

- **Plugins that fill metadata and run on a schedule.** A `metadata`
  plugin runs after the built-in agents and fills or overrides unlocked
  fields; a `task` plugin is a scheduled task in **Settings ▸ Tasks**. Both
  sit behind the per-plugin circuit breaker and the audit log.
- **Audio passthrough on full transcodes.** A client that bitstreams Dolby
  or DTS to a receiver keeps it when the video has to be re-encoded, not
  only on a remux.
- **Video profile and level** in the capability profile: a client can
  declare the highest H.264 / HEVC / AV1 profile and level it decodes, and
  a file above either is transcoded, with the encoder's level set to fit.
  No first-party app sends the keys yet, so their decisions are unchanged.
- **Backups by default**, with a restore drill that proves a dump loads.
- **Monitoring pack** in `deploy/monitoring/`: a Grafana dashboard and
  Prometheus alert rules for the server's metrics.
- **The server stays responsive while it works through a backlog.**
  Trickplay, chapter thumbnails, intro and credits detection run ffmpeg
  with 2 threads at low priority; Home is faster (Memories, Trending and the
  label permission check).
- **Safari plays again**: no more transcode restart loop ending in "rate
  limit exceeded", and no more failure at the start of every stream.
- **Xbox: HEVC, HDR10 and Dolby Vision** in the console's own player, with
  the TV switched into the matching mode; checked on a Series X and an LG
  C1.
- **Roku seek thumbnails** from a server-built BIF.

## Apps

- **Xbox** (served by the server at `/tvapp/`): the native player above,
  controller input fixed (B is Back, once), and Microsoft Store packaging.
  The Store submission is next.
- **Roku:** seek thumbnails, channel art, a capability header that follows
  the device and TV, and Roku's certification hooks (launch beacons, deep
  links). The channel has still not run on a Roku.
- **TV web apps (webOS, Tizen, Xbox):** the Watchlist and Status, the D-pad
  leaves the on-screen keyboards, focus returns to the library you left, a
  stalled request is retried once. Tizen 1.1.2 adds the exit popup
  Samsung's review asked for.
- **Android TV / Fire TV:** the seek bar's scale after taking back
  background audio, Next and Previous for background music and books, and
  background streaming that keeps Wi-Fi awake.
- **Web:** draggable Home rows, tidier library cards and item-page buttons,
  Refresh metadata and Fix Match that say how they went, and better 4K
  Chromecast detection.

## Fixes

- The manual poster picker no longer wipes an item's details.
- EPUBs are named from the book, covers of "advanced" EPUBs show, and book
  downloads carry their own type.
- The Playwright nightly's metrics tests (a CI setup bug; they had never
  passed).

## Known limitations

- Dolby Vision profile 5 files that need a re-encode are refused (no
  tone-mapping to SDR yet). Profile 7 → 8.1 conversion needs the GPU image.
- The Roku channel hasn't run on a device; the Xbox app isn't in the
  Microsoft Store yet.
