# Demo / Review Library — Attribution & Credits

Attribution for the public-domain and Creative Commons media used in the
app-store review demo library (see `demo-review-library.md`). CC-BY requires
crediting the author, source, and license. Public-domain works (LibriVox, NASA)
require no attribution but are credited here as a courtesy.

Surface this on the server's **About** page (or link to it) so attribution is
discoverable. None of it is shown to the store reviewer, but it keeps the CC-BY
