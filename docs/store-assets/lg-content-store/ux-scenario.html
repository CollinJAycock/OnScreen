OnScreen for LG webOS TV

UX scenario · app ID com.onscreen.tv · version 0.2.1 · developer: Collin Aycock (collin.j.aycock@gmail.com)

1. What the app is

OnScreen is the TV client for OnScreen Media Server, free open-source software that people install on their own computer or NAS. The app plays the movies, TV shows, music, audiobooks and photos the user has added to their own server. The app itself contains no content and does not provide, sell or link to any. It has no web browser, no add-ons and no way to open stream links or playlists.

Log-in functionYes. The user enters their server's address, then signs in with that server's username and password. A test account is given below.
In-app purchaseNone. The app is free and sells nothing.
In-app advertisingNone. No ads, no analytics, no tracking.
Privacy policy / termsShown in the app under Settings > About (text and QR code) and Settings > About > Licence & terms. Online: https://onscreen.wolverscreen.com/privacy

How to sign in

  1. Launch the app. The first screen is Add your OnScreen server with an on-screen keyboard.
  2. Type onscreen-beta.wolverscreen.com with the keyboard (D-pad and OK, or point and click with the Magic Remote) and select done. The app tests the connection (https:// is tried first).
  3. The Sign in screen opens. Type the username reviewer and select done.
  4. Type the password and select done. The Home screen opens.

Alternatives on the Sign in screen: Sign in with another device shows a PIN to enter on a phone or computer (not needed for testing); Change server returns to the address screen. Back on the username step returns to the address screen when that screen opened Sign in. The sign-in is remembered: later launches open on Home.

4. Remote control

Every screen works with both the Magic Remote's pointer and its D-pad. Pointing at an item highlights it; OK or a click selects it; the wheel scrolls lists and pages.

Back on the first screen and leaving the app

  • On Home (or on the address / Sign in screens when the app opened there), Back opens an Exit OnScreen? popup with Exit and Cancel; it starts on Cancel. Exit closes the app.
  • On webOS TV 23 and later, Back on that screen shows the TV's Home screen instead, as LG's checklist asks.

Network: the app connects only to the server address entered (port 443 for the test server) and loads the images that server points to, such as film posters from TMDB (image.tmdb.org). It uses one TV permission, systemconfig.query, to read whether the screen supports HDR and 4K.
